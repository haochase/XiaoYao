# 2026-09-12 Day 4 负向同步矩阵

## 验证范围

- DWS project sync CLI：输入校验、artifact/pending/push/end/abort 生命周期。
- 同步 lifecycle：失败后 abort、状态恢复、重复执行和租约边界。
- 同步 orchestrator：collect、artifact、push 失败矩阵与错误类型映射。

## 结果

- 聚焦套件：通过，无失败。
- 覆盖的负向类别包括 `http_error`、`sync_conflict`、`pending_sync_conflict`、非法状态、来源/上下文不一致和失败后清理。
- 两个环境相关用例按既有规则跳过，未将跳过项记为通过。

## 边界

本矩阵是本地合成输入和协议层回归，不是迁移后真实 DWS push 证据。真实 push 仍需在授权、DPAPI 和网关监听条件满足后执行，并要求新鲜 `applied/healthy + end=completed`。
